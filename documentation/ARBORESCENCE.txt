🐍 FICHIERS PYTHON

  📄 main.py
     └─ Point d'entrée principal du projet
     └─ À compléter selon les besoins

  📄 programation.py (8.5 KB)
     └─ Classe Programation
     └─ Gestion de la programmation horaire
     └─ Persistance SQLite
     └─ Gestion de la bibliothèque audio

  📄 player.py (5.6 KB)
     └─ Classe Player
     └─ Lecteur audio avec buffers
     └─ Gestion multi-thread
     └─ Intégration VLC

  📄 interfaces.py (2.6 KB)
     └─ Interfaces abstraites (ABC)
     └─ PlayerInterface
     └─ ProgramationInterface

  📄 player_gui.py (9.9 KB)
     └─ Interface graphique du lecteur
     └─ Contrôle de lecture en temps réel
     └─ Monitoring des buffers
     └─ Gestion du volume

  📄 programation_gui.py (12.4 KB)
     └─ Interface graphique de programmation
     └─ Gestion de la grille horaire
     └─ Gestion des fichiers audio
     └─ Sauvegarde de la programmation

                        🚀 UTILISATION DU PROJET
═══════════════════════════════════════════════════════════════════════════════

1️⃣  INTERFACE DE PROGRAMMATION
    $ python programation_gui.py
    └─ Gérer la grille horaire et les fichiers

    $ python player_gui.py
    └─ Contrôler la diffusion radio

3️⃣  SCRIPT PERSONNALISÉ
    from programation import Programation
    from player import Player
    
    prog = Programation()
    player = Player(prog)
    player.start()
